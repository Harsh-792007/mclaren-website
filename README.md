# 🏎️ McLaren Supercars Showcase Website

A cinematic and interactive McLaren supercars showcase website built using pure frontend technologies.  
The project features immersive video backgrounds, smooth animations, and an engaging UI inspired by McLaren’s high-performance design language.

---

## 🌐 Live Demo
🔗 https://mclaren-website.vercel.app

---

## ✨ Key Features
- Fullscreen background videos for each McLaren model
- Dynamic switching between car models
- Smooth transitions and animations
- Interactive carousel gallery
- 3D rotating video screen effect
- Play / Pause background video controls
- Fully responsive design (desktop & mobile)

---

## 🚗 Models Showcased
- McLaren 765LT Spider  
- McLaren Artura  
- McLaren 750S  
- McLaren 765LT  
- McLaren 750S Spider
